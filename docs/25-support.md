# Support Model

## Customer

Contextual help, safe support code, connection diagnostics, health checklist, Brazilian Portuguese help center, issue reporting, and status communication.

## Support console

Tenant, plan, channel state, sanitized error, webhook timing, job state, Chatwoot linkage, Stripe reconciliation, usage, audit, and correlation IDs.

No raw credentials or automatic unrestricted conversation access.

## Actions

Retry safe processing, retry import, reconcile Stripe, repair Chatwoot, pause AI, guide reconnection, extend authorized pilot, add support note, and export sanitized diagnostics.

## Exceptional access

Requires reason, authorization, time limit, least privilege, audit, and automatic expiry.

## Help topics

Getting started, connecting channels, Coexistence, knowledge, assistant testing, human handoff, team, usage, billing, cancellation, troubleshooting, privacy, and deletion.
